# YOLO Labs

We build [YOLO Studio](https://yolo.studio): cloud development workspaces where autonomous coding agents work in isolated sandboxes, alongside you.

## Open source

| Repo | What it is | Get it |
|---|---|---|
| [yolostart](https://github.com/yolo-labs-hq/yolostart) | Bootstrap a YOLO Studio workspace from your terminal. One native binary, no runtime needed | `curl -fsSL https://yolostart.sh \| sh` |
| [yolo-cli](https://github.com/yolo-labs-hq/yolo-cli) | The `yolo` CLI: workspace context, artifacts, personal apps and hosting | `npm i -g @yolo-labs/yolo-cli` |
| [yolobridge](https://github.com/yolo-labs-hq/yolobridge) | Attach your local Claude Code or Codex to a workspace as a tile | `curl -fsSL https://yolobridge.sh \| sh` |
| [app-sdk](https://github.com/yolo-labs-hq/app-sdk) | Client SDK for building YOLO Studio tile-apps | `npm i @yolo-labs/app-sdk` |
| [flexdb](https://github.com/yolo-labs-hq/flexdb) | MongoDB-like schemaless document store over Cloudflare D1 | `npm i @yolo-labs/flexdb` |
| [videostitcher](https://github.com/yolo-labs-hq/videostitcher) | Automated screencast voiceover pipeline | from source |

These are public mirrors of our monorepo, all MIT licensed. Issues and pull requests are welcome.
